# 国内 LLM Code 模型

## 一、主要国内模型

| 模型 | 定位 | 特点 | 链接 |
|------|------|------|------|
| **智谱 (GLM)** | 通用 + 编码 | 中文优化、高性价比 | https://docs.bigmodel.cn/cn/coding-plan/overview |
| **Kimi** | 长上下文 + 编码 | 支持超长文本、代码能力强 | https://www.kimi.com/code/docs/ |
| **MiniMax** | 通用 + Agent | 高速推理、 Agents 支持 | https://platform.minimaxi.com/subscribe/token-plan |
| **字节 / 阿里 / DeepSeek** | 多元布局 | 各自特色能力 | — |

## 二、特点总结

- **中文优化**：对中文语境、编程习惯有针对性优化
- **成本优势**：相比国外模型，API 费用更低
- **合规适配**：符合国内数据安全法规
- **生态整合**：与国内云服务、工具链深度集成
